# [CUSTOM] 92-Account-Center Release Notes

## Overview
This release introduces critical technical refactors to the 92-Account-Center codebase, addressing architectural debt identified during the recent engineering audit. The primary focus was on transitioning from "functional" implementations to "production-grade" robust patterns.

## 🚀 Key Improvements

### 🛠 Config Service: Transactional Integrity
- **Problem**: Previously, configuration updates and version history creation were non-atomic, risking data-history mismatch.
- **Fix**: Implemented a `WithTransaction` pattern in the `ConfigRepository`. All `UpdateItem` and `ResetItemTo 
Default` operations are now encapsulated in single ACID-compliant transactions, ensuring the version history always matches the current state.

### 💰 Credit Service: Atomicity & Consistency
- **Problem**: Fund transfers (earnings/consumption) could suffer from partial failures where a transaction record was created but the balance was not updated.
- **Fix**: Refactored `EarnCredits` and `ConsumeCredits` to wrap both the transaction logging and the `UpdateBalance` call within a unified database transaction.

### 📈 Data Product Service: Scalability & Performance
- **Problem**: The RFM (Recency, Frequency, Monetary) analysis used $O(N)$ full-table scans, which would cause OOM (Out of Memory) errors as the user base grew.
- **Fix**: 
    - Refactored `GetRFMBatch` to use the SQL `ANY` operator for targeted $O(K)$ lookups.
    - Optimized the data retrieval pipeline by upgrading the `SubscriptionStats` model from `string`-based timestamps to native `time.Time` objects, eliminating expensive `time.Parse`-driven CPU overhead during aggregation.

### 🛡 Compliance Service: Algorithary Precision
- **Problem**: The device fingerprint similarity logic was mathematically inverted, incorrectly reporting high similarity for high-variance (different) device fingerprints.
- **Fix**: Corrected the `calculateFingerprintSimilarity` algorithm to properly compute the normalized Hamming distance, ensuring-true similarity scores.
