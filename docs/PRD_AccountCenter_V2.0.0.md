## 1. 产品概述

### 1.1 产品定位与目标

Account Center（账户管理微服务）是 Neuro 产品线的核心基础设施，承担统一认证、五级身份体系、积分经济、推荐返利、订阅生命周期、RFM 用户画像及合规审计等完整商业闭环。

V1.3.1 已完成全量交付，具备以下能力：

- 8 个 Go 微服务 + 4 端前端（Web/微信小程序/iOS/Android）完整架构
- 51 个 PRD 需求 + 8 个额外功能全部实现
- MLPS 3.0 等保三级合规、SM3/SM4 国密、PII 脱敏中间件、审计日志哈希链
- Docker 全容器化部署、VictoriaMetrics 监控、130+ 配置项驱动运营

V2.0 的核心目标：

1. **商业化上线就绪** — 补齐支付集成、账号注销执行、网关超时等生产级短板
2. **合规红线解除** — 落实账号注销 Worker、密码哈希升级至 argon2id、分布式追踪接入
3. **体验竞争力提升** — 提升测试覆盖率、统一文档体系、构建 K8s 生产级编排

基于 ITERATION V1.0.1 逐行审查，共识别 **77 项改进建议**，按优先级分布：

| 优先级 | 数量 | 定位 |
|--------|------|------|
| P0 | 14 | 上线阻断项，必须在 V2.0 完成 |
| P1 | 30 | 体验与增长关键项，V2.1 迭代 |
| P2 | 29 | 竞争力提升项，V2.2 迭代 |
| P3 | 4 | 长期规划项，V2.3 迭代 |

### 1.3 V2.0 迭代目标

基于 ITERATION V1.0.1 识别的 **8 项已知短板**，作为 V2.0 系列迭代的驱动目标：

1. **测试覆盖率低** — Go 测试文件仅 16/167（~9.6%），5 个服务仅有冒烟测试
2. **文档不一致** — README、ARCHITECTURE.md 与 SSD 之间端口/服务描述存在偏差
3. **密码哈希方案弱** — 使用 SM3+salt（经代码验证确认）而非 bcrypt/argon2，暴力破解防护较弱
4. **无分布式追踪** — 缺少 OpenTelemetry/Jaeger，跨服务问题定位困难
5. **无 K8s 部署** — 仅有 Docker Compose，缺少 Helm/K8s 生产级编排
6. **无真实支付集成** — 订阅购买流程完整但未对接真实支付网关
7. **账号注销未实际执行** — 系统记录注销请求但无后台 Worker 执行数据删除/匿名化（合规红线）
8. **网关无请求超时** — API Gateway 反向代理无 Transport 超时，后端卡死可拖垮全局

**分阶段交付策略**：

| 阶段 | 优先级 | 目标 | 版本 |

## 2. 用户角色与权限

### 2.1 用户角色定义

| 角色 | 说明 | V2.0 变更 |
|------|------|---------|
| 终端用户（L0） | 免费注册用户，基础功能 | 无 |
| 终端用户（L1） | 实名认证用户（个人或企业） | 无 |
| 终端用户（L2） | 付费订阅用户（基础版 Premium T1） | 无 |
| 终端用户（L3） | 高级订阅用户（Premium T2） | 无 |
| 终端用户（L4） | 旗舰订阅用户（Premium T3） | 无 |
| 系统管理员 | 配置管理后台（config-management-ui）运维与系统参数配置 | 无 |
| 运营管理员 | — | **V2.0 新增**（FN-05/FN-06/FN-07/FN-08） |
| 财务管理员 | — | **V2.0 新增**（FN-01/FN-02/FN-03/FN-04） |
| 审计人员 | 合规日志查看，只读权限 | 无 |

> **等级回退规则**：订阅到期且未续费时，用户等级自动回退至 L1（若已实名）或 L0，对应高级权益立即失效。

### 2.2 V2.0 新增角色与权限

#### 运营管理员（V2.0 新增）

- **来源需求**: FN-05, FN-06, FN-07, FN-08
- **权限范围**:
  - **用户管理**：用户列表/搜索/详情、等级调整、积分调整、封禁/解封、实名审核
  - **运营数据**：注册趋势、付费转化漏斗、收入趋势、RFM 分布、推荐 K-factor（Grafana 自定义仪表盘或新建 Admin Dashboard）
  - **订阅管理**：套餐 CRUD（名称/价格/权益/配额）、优惠券/促销活动管理、批量操作
  - **风控管理**：风险事件列表、黑名单管理（IP/设备/用户）、异常注册预警、手动加黑/解黑

#### 财务管理员（V2.0 新增）

- **来源需求**: FN-01, FN-02, FN-03, FN-04
- **权限范围**:
  - **订单管理**：订单查询、导出、状态追踪（待付 → 已付 → 已取消 → 已退款状态机）
  - **支付管理**：支付流水查询（微信支付/支付宝）、退款审核、对账（异步回调处理）
  - **发票管理**：电子发票开具（对接税务系统或第三方发票平台）、邮箱推送
