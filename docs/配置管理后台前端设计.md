
# 配置管理后台前端设计

&gt; **版本**: v1.0.0  
&gt; **日期**: 2026-05-16  
&gt; **阶段**: 阶段4设计完成

---

## 1. 技术选型

| 项目 | 选型 | 理由 |
|------|------|------|
| 前端框架 | Vue 3 + TypeScript | 现代、类型安全、社区成熟 |
| UI组件库 | Element Plus | 组件丰富、成熟稳定 |
| 状态管理 | Pinia | Vue 3官方推荐 |
| 路由 | Vue Router 4 | 官方推荐 |
| HTTP客户端 | Axios | 拦截器、请求取消功能强大 |

---

## 2. 项目结构

```
config-management-ui/
├── src/
│   ├── api/              # API接口封装
│   ├── components/       # 公共组件
│   ├── layouts/          # 布局组件
│   ├── router/           # 路由配置
│   ├── stores/           # Pinia状态管理
│   ├── views/            # 页面组件
│   │   ├── Dashboard.vue      # 首页
│   │   ├── ConfigManagement.vue # 配置管理
│   │   ├── ConfigEdit.vue       # 配置编辑
│   │   ├── ReleaseApproval.vue  # 发布审批
│   │   ├── AuditLog.vue         # 审计日志
│   │   └── PermissionManage.vue # 权限管理
│   └── types/            # TypeScript类型定义
```

---

## 3. 核心页面设计

### 3.1 首页 - 配置总览

**功能**：
- 统计卡片（总配置项、待审批、今日变更、异常告警）
- 最近变更记录列表
- 快捷操作入口

---

### 3.2 配置管理页

**功能**：
- 左侧分组树导航
- 搜索+筛选栏
- 配置列表（卡片/列表视图切换）
- 配置项说明悬停（问号图标）
- 编辑、查看历史操作

---

### 3.3 配置编辑页

**功能**：
- 配置项详情编辑表单
- 数据类型验证
- 变更原因必填
- 保存草稿、提交审批

---

### 3.4 发布审批页

**功能**：
- 待审批发布单列表
- 快速审批（同意/拒绝）
- 查看详情弹窗

---

### 3.5 审计日志页（等保三级）

**功能**：
- 多条件筛选查询
- 日志详情查看
- 导出CSV/PDF

---

## 4. 核心组件

### ConfigHelpTooltip - 配置说明悬停

功能：鼠标悬停问号图标显示配置说明、类型、范围、默认值、最后更新时间。

---

## 5. 权限控制设计

- 路由级权限控制
- 按钮级权限控制
- 系统所有者专属权限（发布审批）
