## 测试范围

覆盖全部 10 个微服务的核心 API 端点，验证端到端业务流程。

## 测试场景

### S1 — 基础设施健康 (10 个端点)
验证所有 10 个服务的 /health 端点返回 200。

### S2 — 用户注册流程 (跨服务)
1. 调用 account-service 发送注册短信验证码
2. 调用 sms-email-service 的短信发送/verify
3. 调用 account-service 完成注册
4. 验证返回 access_token + refresh_token

### S3 — 用户登录流程 (跨服务)
1. 调用 auth-service 密码登录
2. 调用 auth-service 刷新 token
3. 调用 auth-service 登出

### S4 — 密码修改流程 (跨服务)
1. 调用 account-service 发送密码修改验证码
2. 调用 account-service 完成修改密码

### S5 — 账户注销流程 (跨服务)
1. 调用 account-service 请求注销
2. 验证冻结期状态
3. 调用 account-service 取消注销

### S6 — KYB 企业认证
1. 提交企业信息
2. 发起小额打款验证
3. 查看认证状态

### S7 — 审计日志
1. 记录审计日志
2. 按用户查询日志
3. 验证日志完整性
4. 批量记录日志

### S8 — 会话管理
1. 创建会话
2. 验证会话
3. 刷新会话
4. 列出用户会话
5. 使会话失效

### S9 — 风险检测
1. 提交风险评估
2. 查看风险历史

### S10 — 设备指纹
1. 注册设备指纹
2. 验证设备
3. 标记信任设备
4. 获取用户设备列表

### S11 — 邮件服务
1. 发送 OTP
2. 验证 OTP
3. 发送 Magic Link
4. 验证 Magic Link

### S12 — API 网关
1. 健康检查
2. Prometheus metrics
3. 速率限制（超限返回 429）
4. JWT 认证（无 token 返回 401）

## 通过标准

- 每个场景的所有步骤返回预期的 HTTP 状态码
- 核心数据流（注册→登录→使用功能）端到端通
- 错误场景返回正确的错误码
- API 网关认证/限流正常
