# 安全合规说明

## 等保三级 (MLPS 3.0) 合规

本系统按照**网络安全等级保护三级 (MLPS 3.0)** 标准设计，满足以下安全要求：

### 1. 身份鉴别

| 要求 | 实现 |
|------|------|
| 用户身份标识 | UUID + 手机号/邮箱唯一标识 |
| 鉴别凭证 | bcrypt 哈希 + salt |
| 多因素认证 | 支持短信验证码、邮件OTP、Magic Link |
| 会话管理 | JWT 令牌 + Redis 会话存储 |

### 2. 访问控制

| 要求 | 实现 |
|------|------|
| 最小权限原则 | 服务间通过 API Gateway 路由，无直接访问 |
| 角色分离 | 管理员操作需额外验证 |
| 会话超时 | 20 分钟无活动自动失效 |
| 并发限制 | 单用户最多 5 个并发会话 |

### 3. 安全审计

| 要求 | 实现 |
|------|------|
| 操作日志 | 记录所有敏感操作 (登录、密码修改、注销) |
| 日志完整性 | SM3 哈希验证 |
| 日志保留 | 180 天 |
| 日志查询 | 支持按用户、时间范围查询 |

### 4. 数据加密

| 数据类型 | 加密方式 | 说明 |
|----------|----------|------|
| 用户密码 | bcrypt + salt | 不可逆 |
| 身份证号 | SM4-GCM | 企业认证存储 |
| 银行账号 | SM4-GCM | 企业认证存储 |
| JWT 密钥 | 环境变量 | 生产必须修改 |
| 审计日志 | SM3 哈希 | 完整性验证 |

### 5. 通信保密

| 要求 | 实现 |
|------|------|
| HTTPS | API Gateway 支持 SSL |
| 内部通信 | Docker 网络隔离 |
| Token 传输 | Authorization Bearer 头 |

## 密码安全策略

### 密码要求

- 长度: 8-20 位
- 必须包含:
  - 大写字母 (A-Z)
  - 小写字母 (a-z)
  - 数字 (0-9)
  - 特殊字符 (!@#$%^&* 等)

### bcrypt 参数

- Cost: 10 (可调整)
- Salt: 随机 22 字符

---

## 加密实现

### SM4-GCM 加密

```go
// 加密流程
1. 生成 16 字节随机 key
2. 生成 12 字节 nonce
3. 使用 SM4-GCM 加密
4. 返回: nonce + ciphertext (hex 编码)
```

### SM3 哈希

```go
// 审计日志哈希内容
hashInput = userID + actionType + targetResource + sourceIP + result + detailsJSON + eventTime
hash = SM3(hashInput)
```

## 验证码安全

### SMS 验证码

- 长度: 6 位
- 有效期: 5 分钟
- 频率限制: 60 秒内不可重发
- 日发送限制: 10 次/天/手机号

### Email OTP

- 长度: 6 位
- 有效期: 5 分钟
- 频率限制: 3 次/小时/邮箱

### Magic Link

- 格式: JWT 令牌
- 有效期: 15 分钟
- 算法: HS256

## 设备指纹安全

### 可信设备

- 标记有效期: 默认 3 天 (可配置 0-60 天)
- 验证因素: 指纹ID、IP、地理位置
- 风险评分: 0-100

### 异常检测

| 检测类型 | 阈值 | 处理 |
|----------|------|------|
| 地理位置异常 | >1000km/h | 触发验证 |
| 设备变更 | >50% 差异 | 触发验证 |
| 登录频率 | >10次/小时 | 触发验证 |

## 风险控制

### 风险评分

| 分数 | 等级 | 动作 |
|------|------|------|
| 0-30 | 低 | 允许 |
| 31-60 | 中 | 验证 (MFA) |
| 61-80 | 高 | 拒绝 + 告警 |
| 81-100 | 严重 | 拒绝 + 锁定 |

### 会话限制

| 限制项 | 值 |
|--------|-----|
| 最大并发会话 | 5 |
| 会话超时 | 20 分钟 |
| 密码修改后失效 | 是 |
| 账户注销后失效 | 是 |

## 安全建议

### 生产环境

1. **更换默认密钥**
   ```bash
   export JWT_ACCESS_SECRET=<随机256位字符串>
   export JWT_REFRESH_SECRET=<随机256位字符串>
   ```

2. **启用数据库加密**
   - PostgreSQL TDE
   - 备份加密

3. **启用 Redis 认证**
   ```bash
   requirepass <强密码>
   ```

4. **配置防火墙**
   - 仅开放 8080 (API Gateway)
   - 内部服务不对外暴露

5. **定期轮换密钥**
   - 每 90 天更换 JWT 密钥
   - 记录轮换日志

### 监控告警

| 事件 | 告警级别 |
|------|----------|
| 连续 5 次登录失败 | 中 |
| 账户被锁定 | 高 |
| 异常地理位置 | 中 |
| 审计日志验证失败 | 高 |
| 服务熔断器打开 | 中 |
