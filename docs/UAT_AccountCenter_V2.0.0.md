## 1. 验收范围与目标

### 1.1 验收范围

Account Center V2.0 全量功能验收，覆盖以下功能域：

| 功能域 | 涉及服务 | 核心功能 |
|--------|---------|---------|
| 用户认证 | auth-service, api-gateway | 注册、登录、OAuth、生物识别、JWT、企业微信/钉钉 |
| 账户管理 | account-service | 五级身份、个人信息、管理后台、注销 |
| 积分体系 | credit-service | 积分余额、消费、赚取、推荐返利 |
| 订阅管理 | account-service, payment-service | 套餐管理、升降级、续费、退款 |
| 支付系统 | payment-service | 微信支付、支付宝、订单管理、发票 |
| 合规审计 | compliance-service | 风控、审计日志、实名认证 |
| 通知推送 | notification-service | 消息中心、模板管理、推送策略、FAQ |
| 数据产品 | data-product-service | RFM、运营大屏、实时流、A/B测试、广告埋点 |
| 配置管理 | config-service | 热更新、广告配置、FAQ管理 |
| API 网关 | api-gateway | 路由、限流、CORS、JWT、脱敏、版本管理 |
| 基础设施 | 全服务 | K8s、CI/CD、监控、告警、服务发现、熔断 |

### 1.2 验收目标

1. **业务逻辑正确性**：PRD 86 项需求的业务规则全部正确实现
2. **前后端一致性**：Web/iOS/Android/小程序四端展示与后端数据一致
3. **需求完成度**：86 项需求 100% 可追溯到测试用例
4. **用户体验**：核心流程用户可独立完成，任务完成率 ≥90%
5. **安全合规**：等保 2.0 二级控制点全覆盖，PIPL 合规验证通过
6. **质量达标**：GB/T 25000.51 八大质量特性全部评价通过

### 4.2 测试数据

| 数据类型 | 数量 | 说明 |
|---------|------|------|
| 测试用户（L0-L4 各级） | ≥25 | 每级5个，含不同注册方式 |

### 4.3 脱敏策略

- 手机号：保留前3后4，中间用 * 替代
- 邮箱：@前保留首尾字符
- 身份证号：保留前3后4
- 姓名：保留姓氏
