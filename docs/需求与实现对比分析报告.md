# 账户管理微服务 - 需求与实现对比分析报告

本报告对比了账户管理微服务（Account Center）的产品需求、规格文档与当前已实现的功能，识别未完成的需求点以及超出需求范围已实现的功能点。

| 服务 | 端口 | 主要功能 | 实现状态 |

| Auth Service | 30302 | 登录、JWT生成、Magic Link | ✅ 已实现 |
| SMS Service | 30303 | 短信验证码发送 | ✅ 已实现 |
| Email Service | 30308 | 邮件OTP、Magic Link | ✅ 已实现 |
| Device Service | 30309 | 设备指纹、可信设备 | ✅ 已实现 |
| KYB Service | 30304 | 企业认证、小额打款、人脸核身 | ✅ 已实现 |
| Audit Service | 30305 | 审计日志、SM3完整性验证 | ✅ 已实现 |
| Risk Service | 30306 | 风险评估、风险历史 | ✅ 已实现 |
| Session Service | 30307 | 会话管理、强制下线 | ✅ 已实现 |
