## 1. 需求分析

### 1.1 配置项统计

通过全面分析，共识别出 **106个配置项**需要外置化管理：

| 分类 | 配置项数量 | 说明 |
|------|---------|------|
| 后端服务配置 | 75个 | 14个服务 |
| 移动端配置 | 22个 | iOS + Android |
| 额外功能配置 | 9个 | RFM、返佣等 |

### 1.2 核心配置服务分布

| 服务 | 配置项数量 | 重点配置 |
|------|---------|---------|
| RFM Service | 11个 | 评分阈值、计算周期 |
| SMS Service | 10个 | 模板、限流、熔断 |
| Auth Service | 9个 | JWT、密码策略 |
| 推荐返佣 | 5个 | 返佣比例、结算规则 |

## 2. 配置管理架构

### 2.1 整体架构

```
┌─────────────────┐
│ 管理员管理后台  │
└────────┬────────┘
         │
         ▼
┌─────────────────────────┐
│  Config Management API  │
│  (配置管理服务)         │
└────────┬────────────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌──────────┐ ┌─────────┐
│Postgres  │ │  Redis  │
│(持久化)  │ │ (缓存)  │
└──────────┘ └─────────┘
         │
         ▼
    ┌─────────────────┐
    │  所有业务服务  │
    │ (读取配置)      │
    └─────────────────┘
```

### 2.2 配置存储策略

| 配置类型 | 存储方式 | 说明 |
|---------|---------|------|
| 敏感配置 | 环境变量 | JWT密钥、API密钥等 |
| 业务配置 | 数据库+Redis | 可动态调整的配置 |
| 移动端配置 | 远程配置服务 | 颜色、文案、开关 |

## 3. 管理功能设计

### 3.1 核心功能模块

| 功能模块 | 说明 | 优先级 |
|---------|------|------|
| 配置分类管理 | 按服务/功能分组 | P0 |
| 配置CRUD | 新增、编辑、删除配置 | P0 |
| 配置版本历史 | 变更记录、版本回滚 | P0 |
| 配置发布管理 | 草稿、灰度、正式发布 | P1 |
| 权限控制 | 按服务/模块授权 | P1 |
| 配置验证 | 格式、范围、依赖校验 | P1 |

### 3.2 配置项详细分类（示例）

#### 3.2.1 认证服务配置

| 配置项 | 说明 | 数据类型 | 默认值 |
|-------|------|---------|-------|
| JWT_ACCESS_TOKEN_EXPIRE | Access Token有效期 | Duration | 15分钟 |
| JWT_REFRESH_TOKEN_EXPIRE | Refresh Token有效期 | Duration | 7天 |
| PASSWORD_MIN_LENGTH | 密码最小长度 | Integer | 8 |
| LOGIN_MAX_ATTEMPTS | 登录最大失败次数 | Integer | 5 |

#### 3.2.2 短信服务配置

| 配置项 | 说明 | 数据类型 | 默认值 |
|-------|------|---------|-------|
| SMS_PROVIDER | 短信提供商 | Enum | aliyun |
| SMS_CODE_EXPIRE | 验证码有效期 | Duration | 5分钟 |
| SMS_RATE_LIMIT_PER_USER | 单用户频率限制 | RateLimit | 3条/1分钟 |

#### 3.2.3 RFM服务配置（额外功能）

| 配置项 | 说明 | 数据类型 | 默认值 |
|-------|------|---------|-------|
| RFM_RECENCY_DAYS_1 | Recency评分1阈值 | Integer | 3天 |
| RFM_RECENCY_DAYS_2 | Recency评分2阈值 | Integer | 7天 |
| RFM_RECENCY_DAYS_3 | Recency评分3阈值 | Integer | 14天 |
| RFM_RECENCY_DAYS_4 | Recency评分4阈值 | Integer | 30天 |
| RFM_FREQUENCY_TIMES_1 | Frequency评分1阈值 | Integer | 10次 |
| RFM_FREQUENCY_TIMES_2 | Frequency评分2阈值 | Integer | 5次 |
| RFM_FREQUENCY_TIMES_3 | Frequency评分3阈值 | Integer | 2次 |
| RFM_MONETARY_AMOUNT_1 | Monetary评分1阈值 | Decimal | 10000元 |
| RFM_MONETARY_AMOUNT_2 | Monetary评分2阈值 | Decimal | 5000元 |
| RFM_MONETARY_AMOUNT_3 | Monetary评分3阈值 | Decimal | 1000元 |
| RFM_CALCULATION_CRON | 批量计算周期 | Cron | 每日02:00 |
