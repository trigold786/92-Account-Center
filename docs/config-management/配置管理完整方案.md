## 2. 配置管理架构

### 2.1 整体架构

```
┌─────────────────┐
│  管理员管理后台  │
└────────┬────────┘
         │
         ▼
┌─────────────────────────┐
│  Config Management API  │
│  (配置管理服务)         │
└────────┬────────────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌──────────┐ ┌─────────┐
│Postgres  │ │  Redis  │
│(持久化)  │ │ (缓存)  │
└──────────┘ └─────────┘
         │
         ▼
    ┌─────────────────┐
    │  所有业务服务  │
    │ (读取配置)      │
    └─────────────────┘
```

### 2.2 配置存储策略

| 配置类型 | 存储方式 | 说明 |
|---------|---------|------|
| 敏感配置 | 环境变量 | JWT密钥、API密钥等 |
| 业务配置 | 数据库+Redis | 可动态调整的配置 |
| 移动端配置 | 远程配置服务 | 颜色、文案、开关 |

## 4. 等保三级审计日志设计

### 4.1 日志记录要求

| 等保要求项 | 实现方案 |
|----------|---------|
| **完整记录** | 记录所有操作：增删改查配置、登录退出、审批操作 |
| **不可篡改** | 日志写入后禁止修改、删除，记录完整性校验（SM3哈希） |
| **查询追溯** | 支持按时间、操作人、操作类型、配置项多维度查询 |
| **保存期限** | 不少于6个月，支持归档导出 |
| **敏感操作** | 配置发布、权限变更、敏感配置查看单独记录 |

### 4.2 日志记录内容

```
操作ID | 操作时间 | 操作人 | 操作IP | 操作类型 | 操作对象 | 变更前值 | 变更后值 | 操作说明 | 哈希值
```

### 4.3 审计日志功能

- **查询功能**：多条件组合查询、时间范围查询、导出CSV/PDF
- **统计功能**：操作统计报表、变更趋势分析
- **告警功能**：异常操作告警、批量变更告警

## 5. 发布审批流程

### 5.1 流程图

```
1. 编辑配置 → 创建发布单（草稿）
        ↓
2. 提交审批 → 通知系统所有者（系统通知+邮件）
        ↓
3. 系统所有者审批 → [同意/拒绝]
        ↓
4. 同意 → 正式发布生效；拒绝 → 返回修改
```

### 5.2 角色与权限

| 角色 | 权限 |
|------|------|
| **配置编辑者** | 编辑配置、创建发布单、查看审批进度 |
| **系统所有者** | 审批发布单、配置发布权限 |
| **审核员** | 只读审计日志、查看配置历史 |
| **超级管理员** | 全权限 |
