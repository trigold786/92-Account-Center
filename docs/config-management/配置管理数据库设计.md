## 1. 核心表设计

### 1.1 config_groups - 配置分组表

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | BIGSERIAL | 主键 | PRIMARY KEY |
| code | VARCHAR(100) | 分组编码 | NOT NULL, UNIQUE |
| name | VARCHAR(200) | 分组名称 | NOT NULL |
| description | TEXT | 分组描述 | |
| parent_id | BIGINT | 父分组ID | REFERENCES config_groups(id) |
| sort_order | INTEGER | 排序 | DEFAULT 0 |
| is_active | BOOLEAN | 是否启用 | DEFAULT true |
| created_by | BIGINT | 创建人ID | |
| updated_by | BIGINT | 更新人ID | |
| created_at | TIMESTAMPTZ | 创建时间 | DEFAULT NOW() |
| updated_at | TIMESTAMPTZ | 更新时间 | DEFAULT NOW() |

---

### 1.2 config_items - 配置项表

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | BIGSERIAL | 主键 | PRIMARY KEY |
| group_id | BIGINT | 分组ID | REFERENCES config_groups(id), NOT NULL |
| code | VARCHAR(100) | 配置项编码 | NOT NULL, UNIQUE |
| name | VARCHAR(200) | 配置项名称 | NOT NULL |
| description | TEXT | 配置项说明 | NOT NULL |
| data_type | VARCHAR(50) | 数据类型 | NOT NULL, ENUM |
| default_value | TEXT | 默认值 | |
| current_value | TEXT | 当前值 | |
| min_value | NUMERIC | 最小值 | |
| max_value | NUMERIC | 最大值 | |
| options | JSONB | 可选值列表 | |
| validation_rules | JSONB | 验证规则 | |
| is_sensitive | BOOLEAN | 是否敏感配置 | DEFAULT false |
| is_enabled | BOOLEAN | 是否启用 | DEFAULT true |
| sort_order | INTEGER | 排序 | DEFAULT 0 |
| created_by | BIGINT | 创建人ID | |
| updated_by | BIGINT | 更新人ID | |
| created_at | TIMESTAMPTZ | 创建时间 | DEFAULT NOW() |
| updated_at | TIMESTAMPTZ | 更新时间 | DEFAULT NOW() |

**data_type枚举值**: STRING, INTEGER, DECIMAL, BOOLEAN, DURATION, ENUM, LIST, COLOR, CRON, RATE_LIMIT

---

### 1.3 config_versions - 配置版本历史表

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | BIGSERIAL | 主键 | PRIMARY KEY |
| config_item_id | BIGINT | 配置项ID | REFERENCES config_items(id), NOT NULL |
| version_number | INTEGER | 版本号 | NOT NULL |
| value_before | TEXT | 变更前值 | |
| value_after | TEXT | 变更后值 | NOT NULL |
| change_type | VARCHAR(50) | 变更类型 | NOT NULL |
| change_reason | TEXT | 变更原因 | |
| created_by | BIGINT | 操作人ID | NOT NULL |
| created_at | TIMESTAMPTZ | 操作时间 | DEFAULT NOW() |

---

### 1.4 config_releases - 发布申请表

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | BIGSERIAL | 主键 | PRIMARY KEY |

| title | VARCHAR(200) | 发布标题 | NOT NULL |

| submitter_id | BIGINT | 提交人ID | NOT NULL |
| approver_id | BIGINT | 审批人ID | |
| approval_comment | TEXT | 审批意见 | |
| submitted_at | TIMESTAMPTZ | 提交时间 | DEFAULT NOW() |
| approved_at | TIMESTAMPTZ | 审批时间 | |
| published_at | TIMESTAMPTZ | 发布时间 | |

**status枚举值**: DRAFT, SUBMITTED, APPROVED, REJECTED, PUBLISHED

---

### 1.5 audit_logs - 审计日志表（等保三级）

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | BIGSERIAL | 主键 | PRIMARY KEY |
| audit_code | VARCHAR(50) | 日志编号 | NOT NULL, UNIQUE |
| operator_id | BIGINT | 操作人ID | |
| operator_name | VARCHAR(100) | 操作人姓名 | NOT NULL |
| operator_ip | VARCHAR(50) | 操作IP | NOT NULL |
| operation_type | VARCHAR(50) | 操作类型 | NOT NULL |
| target_object | VARCHAR(200) | 操作对象 | NOT NULL |
| value_before | TEXT | 变更前值 | |
| value_after | TEXT | 变更后值 | |
| operation_detail | TEXT | 操作详情 | |
| result | VARCHAR(20) | 操作结果 | NOT NULL, SUCCESS/FAIL |
| sm3_hash | VARCHAR(64) | 完整性哈希值 | NOT NULL |

## 3. 索引设计

### 3.1 config_items 索引

```sql
CREATE INDEX idx_config_items_group_id ON config_items(group_id);
CREATE INDEX idx_config_items_code ON config_items(code);
CREATE INDEX idx_config_items_is_enabled ON config_items(is_enabled);
```

### 3.2 config_versions 索引

```sql
CREATE INDEX idx_config_versions_config_id ON config_versions(config_item_id);
CREATE INDEX idx_config_versions_created_by ON config_versions(created_by);
CREATE INDEX idx_config_versions_created_at ON config_versions(created_at DESC);
```

### 3.3 config_releases 索引

```sql
CREATE INDEX idx_config_releases_status ON config_releases(status);
CREATE INDEX idx_config_releases_submitter ON config_releases(submitter_id);
CREATE INDEX idx_config_releases_created_at ON config_releases(submitted_at DESC);
```

### 3.4 audit_logs 索引（等保三级重点）

```sql
CREATE INDEX idx_audit_logs_operator_id ON audit_logs(operator_id);
CREATE INDEX idx_audit_logs_operation_type ON audit_logs(operation_type);
CREATE INDEX idx_audit_logs_created_at ON audit_logs(created_at DESC);
CREATE INDEX idx_audit_logs_created_at_range ON audit_logs(created_at);
```
